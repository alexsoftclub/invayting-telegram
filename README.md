# Инвайтинг в Telegram: приглашение людей в группы и чаты по списку

Инвайтинг в Telegram - это наполнение группы участниками: аккаунты заходят в чат по ссылке и добавляют туда людей из вашей базы. В **AlexSoftClub** это задача **17 Инвайтер**, режим "Инвайтер": он раздаёт список юзернеймов по аккаунтам и приглашает людей по одному с паузой или быстро, пачками до 100 человек за один запрос.

Сайт: https://alexsoftclub.biz/inviter/ · Документация модуля: https://cli.alexsoftclub.biz/docs/#/Задачи/17_Инвайтер · Связь: [@TGLeadHunter](https://t.me/tgleadhunter)

## Как это работает

1. Аккаунт берёт группу из таблицы `17 2 Инвайтер ссылки на группы` и вступает в неё, если ещё не состоит.
2. Берёт очередного человека: из таблицы `17 1 Инвайтер список пользователей` или из своей контактной книги - это решает настройка "Брать пользователей".
3. Добавляет человека в группу и ставит в `17 1` отметку 🟢 или 🔴.
4. Делает паузу и повторяет до своего лимита. История пишется в `17 4 Инвайтер результаты`.

## Два режима приглашения

**1 - По одному с паузой.** Бережный вариант для основной работы: между людьми выдерживается "Задержка после инвайта".

**2 - Быстрый пачками.** Для задач "залить чат за минуты, аккаунтов не жалко":

- аккаунт сразу забирает из `17 1` всю свою пачку и пробивает юзернеймы подряд, без пауз;
- вся пачка добавляется одним запросом, Telegram принимает до 100 человек за раз; если людей больше, пачка делится, и между частями выдерживается задержка;
- 10 аккаунтов с лимитом `100-100` заливают до 1000 человек за пару минут вместо нескольких часов.

Другие режимы задачи 17 - в отдельных репозиториях: [инвайтинг админами](https://github.com/alexsoftclub/invayting-adminami), [инвайт по ID](https://github.com/alexsoftclub/invayt-po-id), [инвайт из чата-донора](https://github.com/alexsoftclub/invayt-podpischikov-donora). Перед заливом полезен режим "Проверить чат на ограничения" - он ищет теневой бан.

| Брать пользователей (1 - из контактов 2 - из списка) | `2` для работы по списку |
| Режим инвайта (1 - По одному с паузой / 2 - Быстрый пачками) | `1` для бережной работы |
| Кол-во одновременно работающих потоков | `1-3`, в быстром режиме по числу аккаунтов |
| Задержка перед выполнением следующего потока/группы потоков (сек) | `15-40`, в быстром режиме `2-5` |

## Лимиты Telegram

- Безопасная норма - примерно **40-50 приглашений в день на аккаунт** с задержкой 30-60 секунд. Если превышать, аккаунт получает блокировку инвайтов на сутки.
- В один чат один аккаунт может добавить порядка 100-200 человек. Большие объёмы набираются числом аккаунтов, а не лимитом на один.
- Подряд аккаунт может пробить примерно 50-100 юзернеймов, дальше ограничение на часы. Поэтому в быстром режиме лимит выше `100-100` бесполезен, а сами аккаунты расходуются за один-два прохода.
- Людей с приватностью "добавлять могут только контакты" Telegram не пропускает: такие строки получают "Запрет на инвайт". Это нормально, часть аудитории недоступна всегда.
- Один отказ Telegram не блокирует аккаунт: статус "🟧 Нет права приглашать" ставится только после отказа во второй разной группе за запуск или при подтверждённом ограничении.

## Как запустить

1. В SQLiteStudio заполните `17 1` (колонка "✅ Юзернейм") и `17 2` (ссылка на вашу группу).
2. В главном меню мышкой кликните **17 Инвайтер**.
3. В подменю выберите **Инвайтер**.
4. Выставьте настройки и нажмите **"Продолжить"**.
5. Введите задержку старта и нажмите **"Запустить"**.

## Частые вопросы

### Как сделать инвайтинг в Telegram без бана?
Держите 40-50 приглашений в день на аккаунт и задержку 30-60 секунд с разбросом. Используйте режим "По одному с паузой", у каждого аккаунта свой прокси, а новые аккаунты сначала прогрейте.

### Сколько человек можно пригласить в группу с одного аккаунта?
Бережно - около 40-50 в день. В один чат один аккаунт может добавить порядка 100-200 человек, поэтому для больших объёмов нужен пул аккаунтов.

### Можно ли инвайтить в канал?
Нет, инвайтер работает только с группами и чатами. Если по ссылке окажется канал, в `17 2` появится статус "Не инвайчу в канал".

### Почему часть людей не добавляется в группу?
У них закрыта приватность на добавление в группы, и Telegram их не пропускает. Статус "Инвайт запрещен" в `17 2` значит, что приглашения закрыл админ группы.
